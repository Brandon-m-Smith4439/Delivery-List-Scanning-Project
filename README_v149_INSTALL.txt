Delivery List Scanner v149 - Bay Scanner Sticky Fit and Input Refinement
========================================================================

Install over v148:

1. Close the Delivery List Scanner server.
2. Extract this ZIP into the current v148 project folder.
3. Replace included files when prompted.
4. Run Apply-v149-BayScannerStickyFitAndInputRefinement.bat.
5. Restart the scanner normally.
6. Press Ctrl+F5 once in the browser.
7. Run Run-v149-BayScanner-Validation.bat.

The installer creates timestamped backups under:
  backups\v149-bay-scanner\<UTC timestamp>

No database migration or backend patch is required.
No PNG preview files are included.
