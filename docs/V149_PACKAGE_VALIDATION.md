# v149 Changed-Files Package Validation

The v149 package is designed for installation over v148.

Validation covers:

- v149 cache keys and stylesheet ownership
- unique Bay Scanner IDs
- one recent physical movement
- Latest Activity and recent Check feedback
- five-pixel sticky top and bottom viewport fit
- matching fullscreen sticky fit
- non-sticky Bay Map action toolbar
- contained Add destination controls
- condensed Manual Scan controls
- icon-only Undo and Redo controls
- shared application classes on Clear and Manual Submit
- retained v148 structural-history filtering
- balanced CSS and code-only release hygiene

Run `Run-v149-BayScanner-Validation.bat` after installation.
