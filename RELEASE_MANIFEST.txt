Base release
------------
v146 Bay Scanner Workflow Refinement

Install
-------
1. Close the scanner server.
2. Extract this ZIP into the current v146 project folder.
3. Run Apply-v147-BayScannerContainmentRefinement.bat.
4. Restart the scanner and press Ctrl+F5 once.
5. Run Run-v147-BayScanner-Validation.bat.
